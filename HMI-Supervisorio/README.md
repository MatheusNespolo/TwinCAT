# HMI-Supervisorio

Interfaces de operação (TwinCAT HMI / supervisório).

## Projetos

- **[ChangeLanguage](ChangeLanguage/)** — troca de idioma (i18n) em runtime: `Localization/de.localization`, `en.localization`, `Language1.localization`.
- **[ExemploSupervisório](ExemploSupervisório/)** — supervisório (imagens de bomba/reservatório) do exemplo de nível/bomba em [`PLC-Fundamentos/PLC`](../PLC-Fundamentos/PLC/).

## Possíveis assuntos futuros

- Dashboard de produção (KPIs, gráficos de tendência)
- HMI responsivo para mobile/tablet
- Autenticação de usuários (TcHmiUserManagement)

> Os projetos [`TwinCATHMI`](../Inacabados/HMI-Supervisorio/TwinCATHMI/), [`TwinCAT_BSD_CX5240`](../Inacabados/HMI-Supervisorio/TwinCAT_BSD_CX5240/) e [`TF2000eMotion`](../Inacabados/HMI-Supervisorio/TF2000eMotion/) também são desse assunto (apesar do nome do último sugerir motion, o conteúdo é teste de HMI), mas estão em [`Inacabados/`](../Inacabados/) por não terem lógica implementada.
