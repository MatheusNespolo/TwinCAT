# Safety

TwinSAFE: lógica de segurança em terminais FSOES.

## Projetos

- **[SafetyMaua](SafetyMaua/)** — E-stop (`E1`→`S1`), grupo `TwinSafeGroup1` com terminais FSOES reais (EL2904/EL1904). Projeto acadêmico (Instituto Mauá).
- **[SafetyMauaMon](SafetyMauaMon/)** — variante do `SafetyMaua` (mesma estrutura/GUIDs de compileinfo), aparenta ser uma versão de monitoramento do mesmo projeto.

## Possíveis assuntos futuros

- Mais dispositivos FSOES (cortina de luz, scanner de área)
- SafeMotion (integração safety + motion)
- Diagrama de causa-efeito documentado

> O projeto [`SafetyTraining`](../Inacabados/Safety/SafetyTraining/) também é desse assunto, mas está em [`Inacabados/`](../Inacabados/) por não ter nenhum sub-projeto anexado.
